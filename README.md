# Web-Relaunch „Hamburg Jeans“ – Version 2 (Editorial-Design)

Zweiter Design-Entwurf, inspiriert von American Eagle (geteilte Vollbild-Fotos), MAC Jeans (Bild-Text-Wechsel, viel Weißraum) und Armedangels (Bild-Kacheln, Mono-Schrift). Inhalt, Seiten und Funktionen wie in Version 1 (`../hamburg-jeans/`).

- Kein Online-Shop: keine Preise, kein Warenkorb – alle Buttons führen zur Beratung, zum Store oder zur Anfahrt.
- Seiten: Startseite, Wir lieben Jeans, Beratung, Kontakt, Impressum, Datenschutz (+ Danke-Seite nach dem Formular).
- Schriften: Archivo (Überschriften), Inter (Text), IBM Plex Mono (Beschriftungen, Buttons).
- Bilder: echte Ladenfotos und Logos von hamburg-jeans.de, große Stimmungsfotos von Unsplash (Unsplash-Lizenz, Fotografen im Impressum).
- HTML und CSS fehlerfrei im W3C-Validator. `main.js`: mobiles Menü, Öffnungsstatus, Karte nach Klick (kommentiert).
